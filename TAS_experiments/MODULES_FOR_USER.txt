第1部分：需要安装的第三方库（6个）
================================================================================

1️⃣ numpy >= 1.21.0
   - 用途：数值计算、数组操作、矩阵运算
   - 安装：pip install numpy

2️⃣ scipy >= 1.7.0
   - 用途：科学计算、参数优化、统计检验
   - 子模块：scipy.optimize, scipy.stats, scipy.spatial
   - 安装：pip install scipy

3️⃣ pandas >= 1.3.0
   - 用途：数据处理、表格操作、CSV读写
   - 安装：pip install pandas

4️⃣ opencv-python >= 4.5.0
   - 用途：图像处理、颜色空间转换、滤波
   - 安装：pip install opencv-python
   - 备选：pip install opencv-python-headless (无GUI)

5️⃣ Pillow >= 8.3.0
   - 用途：图像加载和保存
   - 导入：from PIL import Image
   - 安装：pip install Pillow

6️⃣ matplotlib >= 3.4.0
   - 用途：数据可视化、绘图
   - 导入：import matplotlib.pyplot as plt
   - 安装：pip install matplotlib

第8部分：常见问题和解决方案
================================================================================

Q1: opencv-python 导入失败？
A: 尝试使用 headless 版本：
   pip uninstall opencv-python
   pip install opencv-python-headless

Q2: scipy 版本太旧？
A: 升级到最新：
   pip install --upgrade scipy

Q3: 权限错误？
A: 使用 --user 标志：
   pip install --user -r requirements.txt

Q4: 在SLURM中安装失败？
A: 修改 submit_experiments.slurm，加入：
   pip install --user -r requirements.txt

Q5: 某个模块一直装不上？
A: 运行诊断脚本：
   python validate_setup.py

第10部分：各模块的详细功能
================================================================================

numpy (数值计算)
  - 核心：n维数组（ndarray）
  - 操作：求和、均值、标准差、矩阵乘法
  - 使用：所有数学计算的基础

scipy (科学计算)
  - optimize：参数优化（differential_evolution）
  - stats：统计计算（相关系数、散度、检验）
  - spatial：距离计算（JS散度）
  - 使用：TAS模型训练和评估指标

pandas (数据处理)
  - DataFrame：表格数据结构
  - 操作：聚合、分组、统计
  - 使用：结果整理和CSV操作

opencv (图像处理)
  - 颜色转换：RGB ↔ YCrCb ↔ Gray
  - 滤波：高斯模糊、拉普拉斯
  - 金字塔：多尺度分析
  - 检测：边缘、形态操作
  - 使用：伪影计算和数据预处理

Pillow (图像I/O)
  - 加载：Image.open()
  - 保存：Image.save()
  - 转换：格式转换
  - 使用：读写JPG文件

matplotlib (可视化)
  - 绘图：线图、散点图、柱状图
  - 保存：savefig() 保存为PNG/PDF
  - 子图：subplot 多图展示
  - 使用：生成论文级别的图表

第11部分：三种安装方式对比
================================================================================

方式1：pip + requirements.txt（推荐）
  优点：一键安装，版本一致，易复现
  时间：10-15分钟
  命令：pip install -r requirements.txt

方式2：pip 逐个安装
  优点：可选版本，灵活性高
  时间：15-20分钟
  命令：pip install numpy scipy pandas ...

方式3：conda 安装
  优点：包管理更完善，环境隔离
  时间：10-15分钟
  命令：conda install numpy scipy pandas ...

推荐选择：方式1（最快最可靠）
