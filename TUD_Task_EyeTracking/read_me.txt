This database contains the following three file folders:

TestImages: contains the 160 images used in the experiment
OriginalContent: Contains the original 40 high quality images used to create the 160 images used in the experiment
SaliencyFreeLook: contains the corresponding saliency maps of the test images, which were collected during a free looking task
SaliencyScoring: contains the corresponding saliency maps of the test images, which were collected during a scoring task

Details about how the data was gathered is detailed in the following paper (the sections explaining phase1 and phase2):
H. Alers, H. Liu, J. Redi and I. Heynderickx, "Studying the risks of optimizing the image quality in saliency regions at the expense of background content ", IS&T/SPIE Electronic Imaging 2010, Image Quality and System Performance VII, Jan 2010
Download from: http://mmi.tudelft.nl/pub/hantao/SPIE10ALERS.pdf
