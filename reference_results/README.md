# Archived reference results

These CSV and JSON files are aggregate or per-stimulus outputs generated by the released experiment scripts and retained to make numerical reproduction auditable. They do not contain dataset images, saliency maps, participant records, or manuscript files.

Directory names match the runtime output directories documented in the [reproducibility guide](../REPRODUCIBILITY.md). Run `python verify_reference_results.py` from the repository root to check the primary values quoted in the paper against this archive.

Generated timestamps and elapsed times are provenance fields from the archived runs. Runtime and the final digits of trained-model results can vary by hardware and software environment.
